# Bitcoin price

Run the script with the bash tool. It lives in this skill's folder: use the full path, `<this skill's directory>/scripts/btc-price`. No API key is needed.

```bash
scripts/btc-price            # BTC: 61,549.00 USD
scripts/btc-price eur gbp    # one line per currency
```

Report the number as given; prices change by the minute.
